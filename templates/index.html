Project description
What is AssistVision Magic Glass?

AssistVision Magic Glass is an assistive vision web application built as part of the Deep Learning final project.

The application is designed with accessibility in mind, particularly for individuals experiencing age-related vision or cognitive decline. When a user uploads a photo, the image is displayed inside a simulated Magic Glass lens and the predicted object name is shown as an overlay — mirroring how the same system could be deployed on real AR smart glasses hardware in the future.

The web app is built with Flask (Python) for the backend and plain HTML/CSS/JS for the frontend. The trained model is saved in Keras format and loaded at server startup for fast inference.
